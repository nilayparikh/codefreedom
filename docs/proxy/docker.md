# Docker Mode

The proxy can run two ways:

| Mode | Command | Requirements | Best for |
| --- | --- | --- | --- |
| **Native** | `codefreedom proxy start` | Python + `litellm` package | Quick local dev |
| **Docker** | `codefreedom proxy start --docker` | Docker + Docker Compose | Isolated, reproducible setups |

## Docker Compose

The `docker-compose.yaml` (generated by `proxy init`) runs the LiteLLM image as a container:

```yaml
services:
  litellm:
    image: ghcr.io/berriai/litellm:v1.87.0
    container_name: litellm-codefreedom
    ports:
      - "0.0.0.0:4000:4000"
    volumes:
      - ./config:/app/litellm-config:ro
    extra_hosts:
      - host.docker.internal:host-gateway
    networks:
      - codefreedom
```

### Key Details

**Config mount** — `./config:/app/litellm-config:ro` mounts `~/.codefreedom/proxy/config/` into the container read-only. The container reads `config.yaml` and provider YAMLs from this path.

**`host.docker.internal`** — The `extra_hosts` entry maps `host.docker.internal` to the host machine. This lets the proxy reach local inference servers (e.g., `http://host.docker.internal:8000/v1`) running on your machine. Without this, the container can't see host ports.

**Environment merging** — Docker Compose interpolates `${VAR}` from `.env.proxy` (lowest priority). System environment variables override `.env.proxy` values. `.env.proxy.secrets` is loaded at runtime by the CodeFreedom CLI.

**Network** — The `codefreedom` bridge network isolates the proxy. Other CodeFreedom containers (sandbox, tools) can join this network to reach the proxy at `http://litellm-codefreedom:4000`.

### Direct Docker Commands

```bash
# Start
docker compose -f ~/.codefreedom/proxy/docker-compose.yaml --profile litellm up -d

# Stop
docker compose -f ~/.codefreedom/proxy/docker-compose.yaml --profile litellm down

# Logs
docker compose -f ~/.codefreedom/proxy/docker-compose.yaml --profile litellm logs -f litellm
```

## Native Mode

Native mode runs LiteLLM directly in Python:

```bash
codefreedom proxy start --port 4000 --host 0.0.0.0
```

This requires the `litellm` package installed (`pip install codefreedom[litellm]`). The proxy reads `~/.codefreedom/proxy/config/config.yaml` directly — no container, no volume mounts.

> **Native mode on ARM64 / Apple Silicon:** Docker Compose mode is recommended. Native mode may have dependency issues on some ARM64 setups.

For more, see [LiteLLM Docker](https://docs.litellm.ai/docs/proxy/docker).
