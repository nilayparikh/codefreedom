# GitHub MCP Server Tool

A Docker container wrapping the official **GitHub MCP Server** (`ghcr.io/github/github-mcp-server`)
with a stdio→HTTP bridge, exposing GitHub API tools (issues, PRs, repos, search, etc.)
via an HTTP MCP endpoint on port 8082.

## Overview

The GitHub MCP Server exposes GitHub's API as MCP tools that coding agents can
use to interact with repositories, issues, pull requests, and more:

- **Repository operations** -- create repos, manage branches, view code
- **Issue management** -- create, update, search, and comment on issues
- **Pull request operations** -- create, review, merge, and manage PRs
- **Code search** -- search across repositories, code, and users
- **Review flow** -- read and submit PR reviews, manage check runs

The wrapper image copies the server binary from the official image and runs a
Python bridge that:
1. Spawns `github-mcp-server stdio` with the PAT from the profile
2. Listens on port 8082 for HTTP JSON-RPC requests
3. Bridges requests/responses between HTTP and stdio

Coding agents connect to `http://127.0.0.1:8082/mcp` — just like the Chrome
and Web tools.

> Requires a **GitHub Personal Access Token (PAT)** with appropriate scope.
> Classic tokens need `repo` and `read:org` scopes. Fine-grained tokens need
> permissions matching the repositories you want to access.

## Usage

```bash
# Initialize the tool profile (accepts third-party notice)
codefreedom tools github init

# Edit ~/.codefreedom/profiles/github.json to add your token:
#   "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_..."

# Start the container
codefreedom tools github start

# Check container status
codefreedom tools github status

# Restart the container (preserves state)
codefreedom tools github restart

# Stop the container
codefreedom tools github stop
```

### Connecting from an Agent

Once running, coding agents can discover the MCP server at:

```
http://127.0.0.1:8082/mcp
```

## Container

The container image (`docker.io/nilayparikh/codefreedom:github-latest`) is a
multi-stage build:

1. **Stage 1:** copies `github-mcp-server` binary from `ghcr.io/github/github-mcp-server`
2. **Stage 2:** `python:3.13-slim` base running `bridge.py` which spawns the
   binary and bridges stdio ↔ HTTP on port 8082

The Dockerfile is at `docker/github/Dockerfile.Github`.

Published tags:

| Tag | Registry |
|-----|----------|
| `github-latest` | `docker.io/nilayparikh/codefreedom` |
| `github-v0.1.0` | `docker.io/nilayparikh/codefreedom` |
| `github-latest` | `ghcr.io/nilayparikh/codefreedom` (mirror) |

The image is automatically built, cosign-signed, and published by the
[`docker-github.yml`](https://github.com/nilayparikh/codefreedom/blob/main/.github/workflows/docker-github.yml)
workflow on changes to `docker/github/Dockerfile.Github`. Multi-arch images
are built for `linux/amd64` and `linux/arm64`.

### Profile and Schema

Settings are stored in `~/.codefreedom/profiles/github.json`, validated
against `~/.codefreedom/profiles/github.schema.json`. Generated by
`codefreedom tools github init`.

| Setting          | Default                                                | Profile override                  |
| ---------------- | ------------------------------------------------------ | --------------------------------- |
| `image`          | `docker.io/nilayparikh/codefreedom:github-latest`      | Change to a specific version tag  |
| `container_name` | `codefreedom-tools-github`                             | Custom container name             |
| `port`           | `8082`                                                 | HTTP MCP server port              |
| `data_dir`       | `~/.codefreedom/sandbox/tools/github`                  | Persistent data mount             |
| `env`            | `GITHUB_PERSONAL_ACCESS_TOKEN: "${GITHUB_PERSONAL_ACCESS_TOKEN}"` | Env vars (token required)  |

### Required Configuration

The `GITHUB_PERSONAL_ACCESS_TOKEN` environment variable **must** be set in
`~/.codefreedom/profiles/github.json` under the `env` section.  You can use
`${GITHUB_PERSONAL_ACCESS_TOKEN}` to reference the token from your system
environment, or hardcode it directly:

```json
{
  "github": {
    "image": "docker.io/nilayparikh/codefreedom:github-latest",
    "container_name": "codefreedom-tools-github",
    "port": 8082,
    "data_dir": "~/.codefreedom/sandbox/tools/github",
    "env": {
      "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_your_token_here"
    }
  }
}
```

## Security Notes

- Store your token securely. The profile file is stored in `~/.codefreedom/profiles/`
  which has restricted permissions.
- The token is injected into the container via environment variable at runtime
  and is not persisted in the container image.
- Use fine-grained PATs scoped only to the repositories you need.
