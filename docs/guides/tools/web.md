# Web Search Tool

A headless browser container for web search and scraping. Runs an
**MCP server on port 8420** exposing `web_search` and `web_fetch` tools.

## Overview

The web tool combines a headless browser with an MCP server for reliable
web automation:

- **Headless browser** -- runs without CDP, presenting a standard browser
  profile to websites
- **Xvfb** -- virtual display at 1920x1080x24 for headed mode
- **PyAutoGUI** -- OS-level mouse/keyboard emulation for complex interactions
- **Built-in fingerprint generation** -- for undetectable automation
- **MCP Streamable HTTP server** -- exposes `web_search` and `web_fetch` tools
  on port 8420

> The MCP server runs inside the container. Coding agents connect to
> `http://localhost:8420` to invoke the tools.

## Usage

```bash
# Initialize the tool profile (accepts third-party notice)
codefreedom tools web init

# Start the container
codefreedom tools web start

# Check container status
codefreedom tools web status

# Restart the container (preserves state)
codefreedom tools web restart

# Stop the container
codefreedom tools web stop
```

### Available MCP Tools

Once the container is running, coding agents can use:

| Tool | Description |
|------|-------------|
| `web_search` | Search the web via configured engines, returns structured results with optional AI summaries |
| `web_fetch` | Fetch a web page's content (text + HTML) with anti-bot evasion |

## Container

The container image is based on `python:3.13-slim` (multi-arch: `linux/arm64`,
`linux/amd64`). It includes:

- Headless browser (Firefox fork) -- [Dockerfile](https://github.com/nilayparikh/codefreedom/blob/main/docker/web/Dockerfile.Web)
- Xvfb (X virtual framebuffer)
- PyAutoGUI (OS-level input automation)
- Built-in fingerprint generation (browser profile)
- MCP Python SDK (Streamable HTTP server)

### Profile and Schema

Settings are stored in `~/.codefreedom/profiles/web.json`, validated
against `~/.codefreedom/profiles/web.schema.json`. Generated by
`codefreedom tools web init`.

| Setting | Default | Profile override (in `web.json`) |
|---------|---------|----------------------------------|
| `image` | `codefreedom:web` | Change to `your-registry/web:latest` |
| `container_name` | `codefreedom-web` | Custom container name |
| `port` | `8420` | MCP server port |
| `mcp_path` | `/mcp` | MCP endpoint path |
| `data_dir` | `~/.codefreedom/sandbox/tools/web` | Persistent data mount |
| `env` | _(none)_ | Extra env vars forwarded to container |
| `search_engines` | `{}` | Search engine URL templates with `{q}` placeholder |
| `search_cooldown_seconds` | `2.0` | Cooldown between MCP search calls |
| `parser_registry` | `{}` | CSS selectors for extracting search results |

Validate your configuration:

```bash
python -m jsonschema \
  ~/.codefreedom/profiles/web.schema.json \
  ~/.codefreedom/profiles/web.json
```

### Configuring Search Engines

Add search engines to the `search_engines` block in `web.json`:

```json
{
  "web": {
    "search_engines": {
      "engine-name": {
        "url": "https://example.com/search?q={q}",
        "parser": "standard"
      }
    }
  }
}
```

Each engine defines a `url` template (use `{q}` for the query) and a `parser`
that references a key in `parser_registry`. The bundled `standard` parser
handles common result layouts.

### Data Persistence

Browser profile data (cookies, sessions, storage) persists in
`~/.codefreedom/sandbox/tools/web/` across container restarts.
