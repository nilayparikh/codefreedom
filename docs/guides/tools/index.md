# Tools

CodeFreedom provides containerized browser tools for coding agents. These tools
run as Docker containers alongside your code agent, exposing MCP servers or
CDP endpoints for web interaction and automation.

Two tools are available:

| Tool                          | Purpose                                                   | Interface     | Profile                | Schema                        |
| ----------------------------- | --------------------------------------------------------- | ------------- | ---------------------- | ----------------------------- |
| [Chrome Browser](chrome.md)   | Headless browser automation via Chrome DevTools Protocol  | CDP port 9222 | `profiles/chrome.json` | `profiles/chrome.schema.json` |
| [Camoufox Web Search](web.md) | Stealth / anti-bot web search and scraping via MCP server | MCP port 8420 | `profiles/web.json`    | `profiles/web.schema.json`    |

Both tools follow the same lifecycle:

```bash
codefreedom tools <tool> init    # Initialize profile + schema (accept third-party notice)
codefreedom tools <tool> start   # Start the container
codefreedom tools <tool> status  # Show container status
codefreedom tools <tool> stop    # Stop and remove the container
```

**Note:** `web` has an alias -- `codefreedom tools camoufox` is equivalent to `codefreedom tools web`.

## Profiles and Schemas

Each tool has a profile file and a JSON Schema in `~/.codefreedom/profiles/`:

| File                 | Purpose                                                            |
| -------------------- | ------------------------------------------------------------------ |
| `chrome.json`        | Chrome container settings (image, port, data directory, env)       |
| `chrome.schema.json` | Schema for validating `chrome.json`                                |
| `web.json`           | Camoufox container settings (image, port, search engines, parsers) |
| `web.schema.json`    | Schema for validating `web.json`                                   |

Profiles are generated by `init` and can be customized afterward. The `$schema`
property in each JSON file points to its schema, so editors with JSON Schema
support provide autocomplete and validation automatically.

See [Profiles](../profiles.md#json-schema-validation) for editor setup and command-line validation.
