# Chrome Browser Tool

A **headless** Google Chrome container for browser automation. Coding
agents connect via the **Chrome DevTools Protocol (CDP)** at port 9222
to drive the browser.

## Overview

The Chrome tool runs plain headless Google Chrome Stable inside a
minimal Docker container:

- **Headless mode** -- no Xvfb, no display server, no PulseAudio
- **No DBus session bus** -- no GCM / registration noise on boot
- **Retail Google Chrome** -- amd64: Google repo; arm64: Chromium
  snapshots (Ubuntu's chromium-browser is a snap shim)
- **`--shm-size=512m`** -- prevents Chrome crashes on `/dev/shm`
- **dumb-init** as PID 1 -- clean process management
- **stderr is filtered** to drop harmless warnings from xkbcomp,
  GCM, Vulkan, and friends

> For **web search and scraping**, use the
> [web tool](web.md) instead. Chrome here is a plain automation target:
> simple, fast, and quiet.

## Usage

```bash
# Initialize the tool profile (accepts third-party notice)
codefreedom tools chrome init

# Start the container
codefreedom tools chrome start

# Get the CDP debug URL for your agent
codefreedom tools chrome url

# Check container status
codefreedom tools chrome status

# Stop the container
codefreedom tools chrome stop
```

### Connecting from an Agent

Use the CDP URL printed by `codefreedom tools chrome url`:

```
devtools://devtools/bundled/inspector.html?ws=127.0.0.1:9222
```

Or point a Playwright/Puppeteer script to `ws://127.0.0.1:9222`.

## Container

The container image is based on `ubuntu:24.04` (multi-arch: `linux/arm64`,
`linux/amd64`). It includes:

- Google Chrome Stable (arm64: Chromium snapshots) -- [Dockerfile](https://github.com/nilayparikh/codefreedom/blob/main/docker/chrome/Dockerfile.Chrome)
- `dumb-init` as PID 1 supervisor
- Minimal shared library set required by headless Chrome

### Profile and Schema

Settings are stored in `~/.codefreedom/profiles/chrome.json`, validated
against `~/.codefreedom/profiles/chrome.schema.json`. Generated by
`codefreedom tools chrome init`.

| Setting          | Default                               | Profile override (in `chrome.json`)     |
| ---------------- | ------------------------------------- | --------------------------------------- |
| `image`          | `codefreedom:chrome`                  | Change to `your-registry/chrome:latest` |
| `container_name` | `codefreedom-chrome`                  | Custom container name                   |
| `port`           | `9222`                                | CDP debug port                          |
| `mcp_port`       | `9223`                                | MCP proxy bridge port                   |
| `mcp_path`       | `/mcp`                                | MCP endpoint path                       |
| `data_dir`       | `~/.codefreedom/sandbox/tools/chrome` | Persistent data mount                   |
| `env`            | `CHROME_DEBUG_PORT=9222`              | Extra env vars forwarded to container   |

Validate your configuration:

```bash
python -m jsonschema \
  ~/.codefreedom/profiles/chrome.schema.json \
  ~/.codefreedom/profiles/chrome.json
```

### Data Persistence

Browser profile data (cookies, localStorage, extensions) persists in
`~/.codefreedom/sandbox/tools/chrome/` across container restarts.
