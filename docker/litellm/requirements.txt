# ── CodeFreedom LiteLLM Proxy — minimal pinned deps ───────────────────────
# LiteLLM itself is installed separately (see Dockerfile.LiteLLM) from
# the git FORK at the tag pinned by the LITELLM_FORK_URL / LITELLM_TAG
# build args, with --no-deps.  That is the switch that keeps the
# enterprise UI + extras off the image: `litellm[proxy]` would pull
# litellm-enterprise, litellm-proxy-extras, granian, pyroscope-io,
# etc. from PyPI as transitive deps.  With --no-deps on the git install
# those are never resolved, and the curated set below is everything the
# proxy + dashboard actually need at runtime.
#
# Scope we keep (matches the user-visible product):
#   - core proxy runtime (fastapi / uvicorn / gunicorn / websockets)
#   - auth + sso for the dashboard (PyJWT, fastapi-sso, cryptography)
#   - database for spend logs / virtual keys / teams (prisma)
#   - cost / observability (prometheus-client)
#   - HTTP / API clients (httpx, aiohttp, openai, boto3)
#   - tokenisation (tiktoken, tokenizers)
#   - background jobs (apscheduler)
#   - utility (jinja2, click, jsonschema, rich, ...)
#
# Scope we strip:
#   - litellm-enterprise            (gated SSO / branding / paywall)
#   - litellm-proxy-extras          (we run `prisma db push` from entrypoint)
#   - granian                       (alternate ASGI; we run on uvicorn)
#   - pyroscope-io, ddtrace, sentry (profiling / APM, not core)
#   - mangum                        (AWS-Lambda adapter; we run in a container)
#   - azure-identity, google-cloud-aiplatform, anthropic[vertex]
#                                   (provider SDKs that are not all needed
#                                    at once; add per-environment)
#   - pypdf, llm-sandbox, detect-secrets, soundfile, polars
#                                   (heavyweight tools the proxy can
#                                    lazy-import only if a model needs them)
#
# Bump deliberately and rebuild the image (and re-test the WebSearch
# count display) on every change.
# ────────────────────────────────────────────────────────────────────────────
